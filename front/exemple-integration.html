Exemple d'intégration du chatbot Amath

Bienvenue sur notre site

Ceci est un exemple de page web avec le chatbot Amath intégré.

Fonctionnalités du chatbot :

  • Assistant virtuel pour les questions sur MFPRSP
  • Interface moderne et responsive
  • Intégration sans conflit avec votre site existant
  • Session persistante pendant la navigation

Vous pouvez voir l'icône de chat dans le coin inférieur droit de votre écran. Cliquez dessus pour commencer une conversation avec Amath !

Comment ça marche :

  1. Cliquez sur l'icône de chat en bas à droite
  2. Le chatbot s'ouvrira dans une fenêtre overlay
  3. Tapez votre message ou utilisez les boutons proposés
  4. Vous pouvez fermer ou redémarrer la conversation à tout moment
